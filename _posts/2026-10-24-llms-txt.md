## 1. `llms.txt` 完整實作（範本與 Node.js / Next.js 自動產生腳本）

### 標準 `llms.txt` 範本

在網站根目錄（`public/llms.txt`）準備標準格式：

```markdown
# 專案名稱 (Project Name)
> 這裡填寫專案的摘要說明，幫助 LLM 在幾秒內理解這個網站的定位與資料範疇。

## 核心文檔 (Core Documentation)
- [API 規格指南](https://yourdomain.com/docs/api.md): 包含 API 認證、Endpoints 與 Response 格式說明
- [產品常見問題](https://yourdomain.com/docs/faq.md): 產品常見問答與技術規格整理

## 完整資料庫 (Full Datasets)
- [全站完整 Markdown 導出](https://yourdomain.com/llms-full.txt): 包含全站所有文件與文章的純文字對照

```

### Node.js / Next.js 自動化產生腳本 (`scripts/generate-llms.ts`)

這個腳本會在編譯期（Build Time）掃描指定目錄下的 Markdown / MDX 檔案，自動生成 `public/llms.txt` 與拼合全站內容的 `public/llms-full.txt`：

```typescript
import fs from 'fs';
import path from 'path';

const SITE_URL = process.env.NEXT_PUBLIC_SITE_URL || 'https://yourdomain.com';
const DOCS_DIR = path.join(process.cwd(), 'content/docs'); // 存放 Markdown 文件的資料夾
const PUBLIC_DIR = path.join(process.cwd(), 'public');

interface DocItem {
  title: string;
  description: string;
  slug: string;
  content: string;
}

function getDocsRecursively(dir: string): DocItem[] {
  if (!fs.existsSync(dir)) return [];
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  let docs: DocItem[] = [];

  for (const entry of entries) {
    const fullPath = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      docs = docs.concat(getDocsRecursively(fullPath));
    } else if (entry.isFile() && (entry.name.endsWith('.md') || entry.name.endsWith('.mdx'))) {
      const rawContent = fs.readFileSync(fullPath, 'utf-8');
      
      // 簡易解析 Frontmatter（也可用 gray-matter 庫處理）
      const titleMatch = rawContent.match(/title:\s*["']?(.*?)["']?\n/);
      const descMatch = rawContent.match(/description:\s*["']?(.*?)["']?\n/);
      
      const relativePath = path.relative(DOCS_DIR, fullPath).replace(/\\/g, '/');
      const slug = relativePath.replace(/\.(md|mdx)$/, '');

      docs.push({
        title: titleMatch ? titleMatch[1] : entry.name,
        description: descMatch ? descMatch[1] : '簡短文件說明',
        slug,
        content: rawContent.replace(/^---[\s\S]*?---/, '').trim(), // 移除 Frontmatter
      });
    }
  }
  return docs;
}

function generateLLMS() {
  const docs = getDocsRecursively(DOCS_DIR);

  // 1. 生成 llms.txt (索引檔)
  let llmsTxt = `# 網站知識庫 (Site Knowledge Base)\n`;
  llmsTxt += `> 本站提供供 AI Agent 與 LLM 高效擷取的核心文件與資料庫。\n\n`;
  llmsTxt += `## 核心文件列表\n`;

  docs.forEach((doc) => {
    llmsTxt += `- [${doc.title}](${SITE_URL}/docs/${doc.slug}): ${doc.description}\n`;
  });

  llmsTxt += `\n## 完整資料集\n`;
  llmsTxt += `- [全站完整 Markdown 導出](${SITE_URL}/llms-full.txt): 包含所有文件的完整文字內容\n`;

  // 2. 生成 llms-full.txt (完整純文字合併檔)
  let llmsFullTxt = `# 全站完整知識庫合併檔\n\n`;
  docs.forEach((doc) => {
    llmsFullTxt += `---\n\n# ${doc.title}\nURL: ${SITE_URL}/docs/${doc.slug}\n\n${doc.content}\n\n`;
  });

  // 寫入 public 資料夾
  if (!fs.existsSync(PUBLIC_DIR)) fs.mkdirSync(PUBLIC_DIR, { recursive: true });
  fs.writeFileSync(path.join(PUBLIC_DIR, 'llms.txt'), llmsTxt);
  fs.writeFileSync(path.join(PUBLIC_DIR, 'llms-full.txt'), llmsFullTxt);

  console.log('✅ llms.txt & llms-full.txt 已成功自動生成！');
}

generateLLMS();

```

*在 `package.json` 中綁定編譯流程：*

```json
"scripts": {
  "prebuild": "tsx scripts/generate-llms.ts",
  "build": "next build"
}

```

## 2. JSON-LD 結構化資料實作 (Schema.org)

JSON-LD 能明確告之 LLM 頁面實體（Entity）間的關係。

### Next.js (App Router) 共用 JSON-LD 元件 (`components/JsonLd.tsx`)

```tsx
import React from 'react';

interface JsonLdProps {
  data: Record<string, any>;
}

export default function JsonLd({ data }: JsonLdProps) {
  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(data) }}
    />
  );
}

```

## 3. 架構檢查與測試工具

部署完成後，可透過以下工具驗證兩者是否被 AI 爬蟲正確識別：

1. **JSON-LD 驗證**：使用 [Google Rich Results Test](https://search.google.com/test/rich-results) 或 [Schema.org Validator](https://validator.schema.org/) 檢查語法正確性。
2. **`llms.txt` 測試**：使用 `curl` 測試伺服器是否正常回應純文字格式：
```bash
curl -I https://yourdomain.com/llms.txt

```


3. **爬蟲存取測試**：檢查 `robots.txt` 是否允許 AI 爬蟲（如 `GPTBot`、`ClaudeBot`、`PerplexityBot`）讀取 `/llms.txt` 與關鍵路徑。
