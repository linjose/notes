Kimi K3 是月之暗面（Moonshot AI）推出的 2.8 兆（2.8T）參數開放權重模型，主打長程程式設計、100 萬 Token 上下文與原生多模態能力。

---

**Kimi K3 核心特點**

* **2.8 兆稀疏 MoE 架構**：擁有 896 個專家，每個 Token 僅激活 16 個專家（約 1.8% 激活率），在極高參數容量下仍保持極佳的推理效率與低成本。
* **100 萬（1M）Token 超長上下文**：可一口氣吞下整個大型專案程式碼庫、設計規範或複雜研究文獻，無需手動切碎檔案。
* **原生視覺閉環（Vision-in-the-Loop）**：原生支援文字、圖片與影片輸入。在前端或遊戲開發時，模型能直接「擷取畫面修訂程式碼」，精準還原參考設計。
* **長程 Agent 與程式設計能力**：在多項前端盲測與程式自動化評測（如 Frontend Code Arena）取得頂尖成績，擅長跨檔案協調、終端機工具整合與自我修正。
