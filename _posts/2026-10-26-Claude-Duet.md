# Claude Duet：從對話式人工智慧邁向主動型 AI Agent 的新發展

技術與產業發展專題｜2026 年 10 月

## 一、前言

生成式人工智慧（Generative AI）的發展，正逐漸從以文字問答、內容生成與程式碼撰寫為主的對話式工具，轉向能夠理解工作情境、主動辨識任務、操作外部應用程式，並持續完成多步驟工作的人工智慧代理（AI Agent）。這項轉變意味著，人工智慧不再只是等待使用者下達指令的工具，而是開始具備一定程度的任務規劃、執行與持續協作能力。

2026 年 10 月 21 日，人工智慧公司 Anthropic 正式推出 Claude Duet 的研究預覽版本。這是一款專為專業工作者與中小企業經營者設計的 AI Agent 應用程式，能夠整合使用者授權的應用程式、整理重要資訊、主動提醒待處理事項，並在使用者離開裝置後，繼續於雲端環境執行交辦任務。當涉及發送訊息、付款、簽署文件或刪除資料等重要操作時，系統則會先徵求使用者同意。

Claude Duet 的重要性，不僅在於增加人工智慧的自動化功能，更在於重新思考人與 AI 的工作關係：使用者不必親自追蹤每一項工作，而是由 AI 協助掌握整體情境、推進任務，並在需要人類判斷時主動提出。

## 二、Claude Duet 的核心定位與技術特色

### （一）從被動問答轉向主動式協作

傳統聊天機器人通常採取「使用者提問、AI 回答」的互動模式。即使模型具備強大的推理能力，使用者仍須主動開啟對話、提供背景資料、追蹤進度，並決定下一步應該執行什麼工作。

Claude Duet 則採取不同的設計方向。它會在每天早晨整理已連接應用程式中的重要事項，提供簡短的工作摘要，並在一天之中定期檢查相關資訊。當系統判斷某件事情值得使用者注意時，便會主動發出通知，而非要求使用者不斷詢問。

例如，當使用者安排了一場重要會議，Claude Duet 可以協助整理相關電子郵件、準備會議摘要，並注意會議時間是否與其他行程衝突。若發現潛在問題，便可主動提出提醒或建議處理方式。

這種設計的關鍵，在於讓 AI 從「回答問題」進一步發展為「理解工作情境並協助推進任務」。不過，主動提醒並不代表系統能夠即時監控所有資料；依照官方說明，Claude Duet 會以固定間隔檢查已連接的帳戶，以控制背景工作所消耗的使用額度。

### （二）以多步驟任務執行取代單次內容生成

Claude Duet 的另一項特色，是能夠接受較高層次的工作目標，再自行規劃所需步驟及選擇適合的工具。

例如，使用者可以要求它協助製作營運儀表板、建立財務或銷售預測、製作簡報、開發網頁應用程式，或處理會議安排與行政事務。這些任務通常不只是產生一段文字，而是需要蒐集資訊、操作不同工具、整理資料、執行多個步驟，最後交付可供使用者檢視的成果。

這代表 AI Agent 的工作單位，正逐漸從「一次回答」轉變為「一項完整任務」。使用者描述預期成果，AI 則負責拆解工作、執行流程、處理過程中的問題，並在需要決策或授權時回到使用者身邊。

### （三）在雲端持續工作，不依賴使用者的本機裝置

Claude Duet 配備自己的雲端虛擬機器與瀏覽器環境，可以在背景執行交辦工作。因此，即使使用者關閉手機應用程式，或暫時離開電腦，任務仍可繼續進行。

這種架構與單純在聊天視窗中生成內容的 AI 工具不同。它讓人工智慧具備較完整的執行環境，可以透過授權的應用程式與連接器處理工作，再將成果交回給使用者。

對企業而言，這種模式特別適合需要跨系統操作的工作，例如彙整郵件與行事曆資訊、追蹤待收款項、準備人事作業資料，以及整理客戶關係管理系統中的業務紀錄。

### （四）整合既有記憶、技能與外部應用程式

Claude Duet 並非完全獨立於 Claude 生態系之外的另一個 AI 模型，而是延伸既有 Claude 能力的代理應用。它可以沿用使用者 Claude 帳戶中的記憶、技能與應用程式連接設定，降低重新設定工作環境及重複提供背景資訊的成本。

在外部工具整合方面，Anthropic 表示，Claude Duet 可使用 Claude Marketplace 中超過 6,000 個連接器與外掛程式，涵蓋電子郵件、通訊、財務、人力資源、客戶關係管理、電子簽署及電子商務等應用情境。對於尚未提供連接器的網站，系統也可以透過自己的雲端瀏覽器執行部分操作。

## 三、系統架構與運作模式

從產品公開的功能來看，Claude Duet 可以從以下四個層次理解。這是依照其公開功能所做的概念性整理，並非 Anthropic 公布的完整內部系統架構。

### 第一層：使用者互動

文字與語音指令、工作目標、任務確認與審核

### 第二層：AI 推理與任務規劃

Claude Opus 5.5、工作脈絡、記憶、技能、任務拆解與判斷

### 第三層：雲端執行環境

虛擬機器、瀏覽器、外部連接器與應用程式操作

### 第四層：成果交付與安全控制

文件、報表、儀表板、工作狀態、操作授權與風險防護

概念示意：依 Anthropic 公開的產品功能與運作方式整理。

這種架構的核心，是將模型的推理能力與實際執行環境結合。模型負責理解需求、規劃工作與選擇行動；雲端執行環境則提供操作應用程式所需的工具；安全控制機制負責限制高風險操作，並讓使用者保有最終決定權。

值得注意的是，Claude Duet 目前主要是以產品服務的形式提供使用者，而不是一套可以直接下載、部署於自有伺服器的完整開源 Agent 框架。因此，若企業要建置自主可控的 AI Agent 平台，仍須另外評估模型部署方式、執行環境、工具協定、權限管理與資料治理等需求。

## 四、安全性、隱私與人類監督

AI Agent 能夠代替人類操作外部系統，也意味著其錯誤可能造成實際後果。相較於只提供錯誤文字答案的聊天機器人，能夠寄送郵件、執行付款或刪除資料的代理系統，需要更嚴謹的安全設計。

Claude Duet 在這方面採取數項措施。

第一，重要操作需要使用者核准。 系統可以自行閱讀資訊、準備草稿及推進任務，但在發送訊息、付款、簽署文件或刪除資料之前，會向使用者呈現預定操作並等待同意。部分操作，例如證券交易及帳戶間資金轉移，即使使用者同意也不允許執行。

第二，降低憑證與敏感資料暴露的風險。 Anthropic 表示，系統的憑證處理設計讓 Claude Duet 不會直接看到使用者的密碼或登入權杖；此外，系統會對準備送出的訊息進行額外檢查，以降低信用卡號、政府身分識別資料等高度敏感資訊遭到不當傳送的風險。

第三，防範提示注入與惡意指令。 由於 AI Agent 需要閱讀電子郵件、網頁與其他第三方內容，這些資料可能包含企圖誤導模型的隱藏指令。Anthropic 將相關防護機制納入產品設計，並透過安全測試與漏洞回報計畫持續改善。

然而，這些措施並不代表系統已經完全消除風險。Anthropic 也明確指出，Claude Duet 仍可能誤讀對話、錯判事項的重要性，或未能及時發現檢查間隔內新出現的緊急事件。

因此，Claude Duet 所呈現的治理原則，是讓 AI 在低風險、可逆的工作中保有較高自主性，而在涉及金錢、對外承諾、敏感資料及不可逆操作時，保留人類的監督與核准機制。

## 六、與傳統聊天機器人及一般 AI Agent 的差異

Claude Duet 並不是第一個具備工具操作能力的 AI Agent。其特色在於把主動提醒、持續執行、外部應用程式整合與人類核准機制，整合成一個面向日常工作的產品。

| 比較面向 | 傳統聊天機器人       | Claude Duet               |
| ---- | ------------- | ------------------------- |
| 互動模式 | 主要由使用者主動提問    | 可主動整理資訊及通知使用者             |
| 工作方式 | 以對話、分析與內容生成為主 | 可規劃並執行多步驟任務               |
| 執行時間 | 通常隨使用者互動進行    | 可在雲端背景持續工作                |
| 外部工具 | 依產品功能提供整合     | 整合連接器、外掛程式及雲端瀏覽器          |
| 工作脈絡 | 視對話與產品記憶而定    | 可沿用 Claude 帳戶中的記憶、技能及連接設定 |
| 重要操作 | 依各產品功能而異      | 重要操作須經使用者核准               |

這項發展也反映了產業競爭方向的轉變。AI 產品的差異化不再僅限於模型基準測試、推理能力或生成品質，也開始延伸至任務完成率、工作連續性、工具整合程度、主動判斷能力及權限治理。

## 七、目前的限制與使用條件

截至 2026 年 10 月 26 日，Claude Duet 仍處於研究預覽階段，並非已全面開放的正式產品。

- 使用資格： 目前僅透過等候名單，向美國地區的 Claude Pro 與 Max 訂閱者分批開放；Team 與 Enterprise 方案尚未納入。
- 使用成本： 研究預覽期間不另收費，但會與原有 Claude 方案共用使用額度，背景檢查及較大型任務也會消耗額度。
- 功能限制： 目前無法直接觀看或接管代理所使用的雲端瀏覽器；部分連接器功能仍有限制，Microsoft 365 尚未提供支援。
- 工作範圍： 系統並非可以讀取使用者電腦中所有專案與檔案，也不適合假設所有個人事務都能自動完成。
- 可靠性： 系統可能誤判資訊的重要性或錯誤理解內容，因此使用者仍須審查成果及重要操作。

## 八、結論：AI Agent 將如何改變工作方式？

Claude Duet 展示了人工智慧產品的一項重要發展方向：從提供智慧建議的工具，轉變為能夠主動參與工作、跨越應用程式執行任務，並在需要人類判斷時尋求授權的數位協作者。

其核心價值可以歸納為三個面向。首先，透過主動整理資訊與追蹤工作，降低使用者管理大量待辦事項的負擔。其次，透過雲端執行環境及外部工具整合，將模型能力轉化為實際的工作成果。最後，透過權限限制、敏感資料防護與人類核准機制，嘗試在自主執行與責任控制之間取得平衡。

不過，真正成熟的 AI Agent 不應只以能夠執行多少步驟衡量，也必須考量任務是否正確完成、是否能夠追溯執行過程、能否安全處理例外，以及是否在適當的時機交由人類決策。

從企業數位轉型的角度來看，Claude Duet 的意義在於提醒組織：導入 AI 不應停留在讓員工使用聊天機器人，而應進一步重新設計工作流程、系統介接與授權制度，讓 AI 能夠在明確的責任邊界內承擔工作。當人工智慧從「協助人類思考」逐漸走向「與人類共同完成任務」，組織的競爭力將越來越取決於能否有效結合 AI 的執行能力、人類的判斷力，以及可靠的治理機制。
