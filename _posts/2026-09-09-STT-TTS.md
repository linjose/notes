
### 語音模型STT/TTS
| 類型                  | 代表模型                              | 用途              | 易用性  |
| ------------------- | --------------------------------- | --------------- | ----- |
| 🎙️ 語音轉文字 STT       | **Whisper**                       | 錄音→文字           | ⭐⭐⭐⭐⭐ |
| 🎙️ 語音轉文字           | **FunASR**                        | 中文、中文語音辨識       | ⭐⭐⭐⭐⭐ |
| 🎙️ 語音轉文字           | **SenseVoice**                    | 中文、多語言、情緒/事件辨識  | ⭐⭐⭐⭐⭐ |
| 🗣️ 文字轉語音 TTS       | **Piper**                         | 本地快速朗讀          | ⭐⭐⭐⭐  |
| 🗣️ 文字轉語音           | **CosyVoice**                     | 中文、多語言、高品質      | ⭐⭐⭐⭐⭐ |
| 🗣️ 文字轉語音           | **Fish Speech**                   | 高品質、多語言、聲音克隆    | ⭐⭐⭐⭐⭐ |
| 🗣️ 文字轉語音           | **Qwen3-TTS**                     | 新一代多語言 TTS、聲音控制 | ⭐⭐⭐⭐⭐ |
| 🗣️ 語音→語音           | **GPT-SoVITS**                    | 聲音克隆、少量樣本訓練     | ⭐⭐⭐⭐  |
| 🤖 Speech-to-Speech | **Moshi**                         | 直接語音對話          | ⭐⭐⭐   |
| 🤖 Speech LLM       | **Qwen2-Audio / Qwen2.5-Omni 系列** | 聽懂語音＋理解內容       | ⭐⭐⭐⭐⭐ |

### 多個語言模型整合
```text
🎤 使用者說話
       ↓
   Whisper / FunASR
       ↓
    語音轉文字
       ↓
 PostgreSQL + pgvector
       ↓
   ISO 文件 RAG
       ↓
      LLM
       ↓
   答案 / 引用條文
       ↓
 CosyVoice / Qwen3-TTS
       ↓
🔊 用語音回答
```
